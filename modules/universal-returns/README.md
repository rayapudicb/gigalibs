# Returns and RMA

Generated by `pnpm module:new universal-returns` (WI-OI-085). A business module on the core module SDK (ADR-0013): its own
API service, schema (`gigalibs_universal_returns`) and least-privilege role, reached by the web only through its manifest-declared
gateway `/api/universal-returns` with a platform context the BFF signs for audience `gigalibs-universal-returns-api`.

Start from the `records` resource, then replace it with the module's own resources. Keep:
- every route behind `AuthorizationGuard` with `@RequirePermissions('universal-returns.<area>.<action>')`;
- every statement in `DatabaseService.withTenantTransaction`, and every change followed by `recordMutation`;
- forward-only migrations listed in `db/runtime-manifest.txt`, each table with forced RLS on `app.tenant_id`.

It runs inside the shared module host. Run it (see `infra/compose/README.md`, "Generated modules"):

```bash
pnpm install && pnpm modules:catalog
infra/compose/scripts/generate-generated-module-credentials.sh universal-returns
infra/compose/scripts/build-module-host-image.sh
pnpm module:conformance universal-returns --live
```
