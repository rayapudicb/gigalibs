# Manufacturing & MRP

Generated by `pnpm module:new universal-manufacturing` (WI-OI-085). A business module on the core module SDK (ADR-0013): its own
API service, schema (`gigalibs_universal_manufacturing`) and least-privilege role, reached by the web only through its manifest-declared
gateway `/api/universal-manufacturing` with a platform context the BFF signs for audience `gigalibs-universal-manufacturing-api`.

WI-OI-126 adds BOMs, production orders, MRP preview (`v1/boms`, `v1/production-orders`, `v1/mrp/preview`) plus the
`@gigalibs/universal-manufacturing-web` workspace. The generic `records` resource remains for metadata parity. Keep:
- every route behind `AuthorizationGuard` with `@RequirePermissions('universal-manufacturing.<area>.<action>')`;
- every statement in `DatabaseService.withTenantTransaction`, and every change followed by `recordMutation`;
- forward-only migrations listed in `db/runtime-manifest.txt`, each table with forced RLS on `app.tenant_id`.

It runs inside the shared module host. Run it (see `infra/compose/README.md`, "Generated modules"):

```bash
pnpm install && pnpm modules:catalog
infra/compose/scripts/generate-generated-module-credentials.sh universal-manufacturing
infra/compose/scripts/build-module-host-image.sh
pnpm module:conformance universal-manufacturing --live
```

It stays `readiness: PLANNED` until it passes conformance and is reviewed.
