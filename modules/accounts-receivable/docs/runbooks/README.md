# Required operational runbooks

Before G5, this directory must contain exercised procedures for startup/configuration failure, database
migration and roll-forward, backup/restore/DR, invoice-number contention, outbox backlog, document failure,
email outage, payment webhook/reconciliation failure, credential rotation, tenant export/erasure/legal hold,
security incident, SLO alerts, capacity/noisy-neighbor response, and release rollback/halt.
