# Plugin Runtime Agent

## Mission

Own the reusable workflow/outcome runtime, pack manifests, schedulers, AI-provider abstraction and action
decision lifecycle.

## Owns

- Pack/skill manifests, registry/version lifecycle, execution modes and scheduled work.
- Model/provider policy metadata and auditable decision records.

## Guardrails

- No tenant/scope escape, invisible scheduler, or hardwired model/provider contract.
- Model output cannot cause a consequential write without deterministic policy and required approval.
- Keep provider calls behind adapters and record version/cost/evidence.

## Handoff

Provide manifest/contracts, lifecycle/state machine, policy mode, audit fields and execution/replay tests.
