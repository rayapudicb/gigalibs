## 1. Business event

| Item | Value |
|------|--------|
| Trigger | Inventory receipt **complete** (lifecycle F1.3) |
| Outbox event | `inventory.receipt.completed.v1` |
| Relay | Inventory module-host → Finance internal inbox |

## 2. Spec vs implemented journal (per receipt line with quantity > 0)

| Spec (MODULE_ACTION_OUTCOMES §3) | Implemented (Finance) |
|----------------------------------|------------------------|
| Dr **Inventory asset** / Cr **GRNI** at PO cost | Dr `cost_profiles.inventory_gl_account_id` / Cr `cost_profiles.grni_gl_account_id` for `totalCostMinor` (qty × unit cost from default active cost profile’s **standard_unit_cost_scaled**) |
| Standard costing: **PPV** to variance | When `costing_method = STANDARD` and standard ≠ actual, additional line(s) on `purchase_price_variance_gl_account_id` (favorable / unfavorable) per `calculatePurchasePriceVariance` |
| Entry type | `SUBLEDGER_INVENTORY` |
| Source document | `INVENTORY_RECEIPT` + line id `{receiptId}:{receiptLineId}` |

**Not in this slice (accountant to confirm deferral is acceptable for Phase 1 Table 2):**

- PO line matching (`MatchPO`) before complete — operational matching not enforced on complete.
- Per-PO **actual** unit cost from Procurement — posting uses **default cost profile standard** until extended.
- Multi-currency — journal lines currently use **USD** in costing handoff (tenant book currency should be verified on UAT).

## 3. Preconditions enforced before journal posts

| Check | Where | On failure |
|-------|--------|------------|
| Payload valid | Finance inbox | `POSTING_REJECTED` / inbox FAILED |
| Open fiscal period | `resolvePrimaryBookPostingContext` | `FINANCE_PERIOD_*` rejection codes |
| Default cost profile + standard cost | Inbox apply | `FINANCE_COST_PROFILE_MISSING` |
| Period lock at complete (Inventory) | F1.4 guard when Finance DSN configured | HTTP 400 before stock/outbox |
| Period close (Finance) | F2.8 | Period / Inventory subledger lock blocked if reconciliation gaps |
