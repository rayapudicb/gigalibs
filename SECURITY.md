# Security policy

## Reporting a vulnerability

Do not report a suspected vulnerability in a public issue. Use GitHub private vulnerability reporting
for this repository. The repository owner must enable that feature before public launch.

Include the affected version, impact, reproduction steps, and any safe proof. Do not access customer data,
degrade a service, or retain secrets while testing.

## Supported versions

No production release is currently supported. Supported module and product versions will be listed here
only after G6 release authorization.

## Security boundary

Prototype and quarantined code is not a supported security boundary. See `config/runtime-quarantine.json`
and `docs/runtime-quarantine.md`.
