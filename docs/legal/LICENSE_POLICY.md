# GigaLibs license policy

Status: proprietary public-source policy  
Effective: 2026-09-04

The repository is publicly visible for product development and review, but it is not open source. The root
`LICENSE` reserves all rights. External use, copying, modification, hosting, redistribution, and derivative
works require written authorization from the copyright owner.

## Future change path

The owner may later select an open-source, source-available, commercial, or dual-license model. Such a
change requires:

- a named copyright holder and legal review;
- an inventory of third-party code, generated code, assets, and their obligations;
- a contribution policy, including a CLA or DCO decision;
- compatibility review for SaaS, customer-cloud, self-contained, and air-gap distribution;
- updated package metadata, notices, SBOM policy, documentation, and release artifacts; and
- an explicit effective version/date. A later license does not silently apply retroactively.

## Invoice Ninja boundary

Invoice Ninja 5 source is not copied into GigaLibs. Its Elastic License 2.0 managed-service restriction is
incompatible with using a substantial set of that software's functionality to provide the planned hosted
GigaLibs SaaS. GigaLibs AR is a clean-room implementation based on independently written requirements,
public standards, and GigaLibs-owned code.
